How to Run the Projects

1. Clone this repository:

git clone (https://github.com/worldishealth11-code/Datheon-python-projects.git)

2. Open the project folder in Visual Studio Code.

3. Navigate to the project you want to run.

4. Run its Python file using:

python organizer.py
python hangman.py
python chatbot.py
python portfolio.py

Replace with the actual Python file name.
